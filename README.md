Capão da Canoa, RS · Estudante de Análise e Desenvolvimento de Sistemas na ULBRA · Inglês fluente

Construo aplicações completas, do modelo de dados à interface. No front-end trabalho com React.js, Next.js e TypeScript; no back-end, com Laravel e Supabase (PostgreSQL, Row Level Security, Edge Functions).

Uso agentes de IA (Claude Code e Codex) dentro de um processo organizado: especificação antes do código, decisões de arquitetura documentadas e backlog por sprint. Os arquivos `SPEC.md`, `AGENTS.md` e `docs/` dos meus projetos mostram esse processo.
